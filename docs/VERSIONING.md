# 版本策略

FinRisk Agent Studio 使用小版本路线和完整语义发布号。

## 对外版本

| 场景 | 格式 | 当前值 |
| --- | --- | --- |
| 文档、路线图、产品范围 | `v0.MINOR` | `v0.1` |
| Python/前端包 | `0.MINOR.PATCH` | `0.1.0` |
| Git 发布 tag | `v0.MINOR.PATCH` | 尚未创建 |

`v0.1` 表示当前产品范围；实际发布提交使用 `v0.1.0` tag。补丁修复使用 `v0.1.1`、`v0.1.2`，新增向后兼容能力进入 `v0.2`/`0.2.0`。

## 当前状态

仓库当前是 `v0.1` release candidate，仍为 `Unreleased`。只有创建对应 Git tag 后才能称为已发布。

发布前必须满足 [STATUS.md](STATUS.md) 的完成定义和 [ROADMAP.md](ROADMAP.md) 的 v0.1 退出条件。

## 版本规则

- `0.x`：产品仍在快速迭代，接口和数据结构可能调整，但数据库变化必须有迁移策略。
- `PATCH`：不改变产品范围的兼容修复。
- `MINOR`：新增向后兼容的产品能力或重要工作流。
- `1.0.0`：核心研究闭环、恢复策略和兼容承诺达到稳定状态。

不再使用 `v15`、`v16`、`v21` 之类实施序号作为文档版本。内部代码中保留的旧类名或字段名属于兼容接口，不代表产品版本。
