# Paired coverage and non-US discovery acceptance protocol

Freeze the pipeline and protocol before selecting a company in a third industry. Use one complete annual PDF. The only additional runtime inputs are service settings, observation date and output locations. Neither run receives a company-specific map, source URL for an external event, hint, or answer key.

Use the same page windows, evidence rules, prompt, model and cached page decisions in both arms. The first arm takes the first eight distinct pages of the existing business/segment ranker, completing to eight by keyword rank. The second consumes every physical page including notes and tables. Count unique typed, directed relationships rather than repeated mentions. The measured universe is the issuer's named reporting segments and explicit segment assignments to marketed products/product families, named inputs, facilities, suppliers, customers/customer classes and operating regions. A corporate-level geographic presence, development pipeline or marketing category alone cannot establish a segment assignment. Record abstentions as unknown, exclude them from factual graph traversal, and include missed reference edges in the recall denominator. This measurement is a controlled page-budget comparison; the older single-call 15-candidate cap is not imposed on the whole document.

After both snapshots are sealed, independently label the source PDF, without providing the original page ranking, candidate edges, graph, search traces, or results to the labeler. Retain page-specific spans, collapse repeated disclosures and document evidence-based equivalences. Count TP, FP and FN for both arms. Precision = TP / (TP + FP); recall = TP / (TP + FN). Report denominators and unmatched records. A zero denominator is undefined. Partition missed edges by absence from selected evidence pages, failure to propose, and audit abstention. Reference coverage and ambiguity must be reported.

Disable US primary sources and bypass the Federal Register adapter. Use target names generated from verified relationships to search general government publications and the UK government's public catalogue. Require a dated, archived non-US primary document, a passage restricted to the same entity and action, a supported product/segment link, and successful Neo4j readback. Report eight-page and full-document outcomes separately even if both fail. An independently checked original-to-segment path is the minimum external pass. Realized impact, fulfillment and attributable amounts stay unknown absent direct proof. Preserve failed runs. Post-freeze repairs are reported separately.
