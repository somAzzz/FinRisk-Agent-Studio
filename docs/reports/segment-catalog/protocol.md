# Catalog continuation acceptance protocol

Run both complete, unchanged PDFs with the annual report as the only issuer input. Use the existing model configuration, OCR routing, reference aliases, and independent disclosure review. The preceding segment-recall run is the baseline. References and target names are evaluation inputs only.

1. A separately named unmarked device needs an explicit local business heading, an equipment heading, a commercial catalog entry naming the device alongside its host, and a positive sales row assigning that host to the same segment.
2. A family in a continuation column needs a bounded catalog heading and a directly listed member independently allocated to the segment. Seek a second in-group co-listing with a segment-sales anchor. This establishes participation in the family, never exclusive ownership or allocation of siblings.
3. A treatment class needs a bounded commercial heading with a marketed entry and a unique explicit condition in the issuer's formal segment scope. Narrow grammatical variants are candidates only, subject to independent semantic review.
4. A named brand beneath such a class additionally needs its own primary bullet inside that same group. No propagation through another heading or into another column.

Pass only if the full 137- and 433-page runs retain all 54 and 14 prior matching triples, add exactly the four specified Novo relations and none at TRATON, have zero false positives against the unchanged references, and keep all other 18 prior Novo misses unallocated. Replay accepted quotes against the original PDFs, including cross-page chains. Unknown includes never proposed; distinguish that from an explicit abstention. Report family participation separately from product revenue or exclusive allocation.
