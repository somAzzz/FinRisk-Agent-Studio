# 历史归档

本目录保存已经完成、被替代或仅供追溯的项目材料。归档不表示内容无价值，只表示它不再是当前工作的首要事实来源。

## 目录说明

- `foundation/`：早期总体架构与长期路线设想。
- `implementation-plans/`：历史 ID 00–21 的阶段实施计划；[总览](implementation-plans/00-overview.md)。
- `reports/audits/`：阶段性代码与系统审计。
- `reports/validation/`：过去的端到端验证记录。
- `reports/traces/`：验证过程产生的结构化运行轨迹。
- `superpowers/`：按日期保存的专项设计与实施草案。
- [notes.md](notes.md)：早期零散项目笔记。

当前结论和路线图请回到 [文档中心](../README.md) 或 [当前项目状态](../current/README.md)。

历史 ID 与产品发布版本的区别见 [产品版本策略](../VERSIONING.md)。
